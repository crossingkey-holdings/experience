# AI Output Evaluation Rubric

Score each dimension from 0–3.

## Instruction adherence
3 complete; 2 minor omission; 1 partial; 0 contradicted or ignored.

## Factual and technical correctness
3 accurate; 2 small non-material issue; 1 meaningful error; 0 unusable.

## Context preservation
3 preserves settled decisions; 2 minor drift; 1 loses important context; 0 contradicts established state.

## Execution readiness
3 concrete and complete; 2 usable with small edits; 1 incomplete; 0 placeholder-heavy or non-executable.

## Failure awareness
3 identifies uncertainty and tool limits correctly; 2 minor ambiguity; 1 overstates confidence; 0 fabricates completion or evidence.

Record the failure class, the smallest correction that fixes it, and whether the correction risks regression elsewhere.
